# Hone

**یک بستهٔ کوچک و صاحب‌نظر از اسکیل‌ها برای عامل‌های کدنویس هوش مصنوعی. نُه اسکیل، صفر وابستگی، بدون
هیچ اسکریپت نصبی — فقط متنی که مدل وقتی دارد حدس می‌زند، بارش می‌کند.**

[English](README.md) · **فارسی**

عاملی که دستور ندارد، کارِ با اعتمادبه‌نفس می‌کند. از او می‌پرسی چرا دو ماشین به هم وصل نمی‌شوند،
می‌رود یک کتابخانهٔ کشف دستگاه اضافه می‌کند. می‌گویی بیلد را منتشر کن، چون یک فایل ساخته شد می‌گوید
موفق. می‌گویی این دیف را مرور کن، ایرادهای سبک را فهرست می‌کند و باگ از دست رفتن داده را نمی‌بیند.
این اسکیل‌ها برای قطع کردن همان خطا نوشته شده‌اند — نه برای آموزش یک فریم‌ورک، بلکه برای اینکه عامل
**قبل از ادعا کردن، بررسی کند**.

هر اسکیل یک پوشه است با `SKILL.md` که در frontmatter آن نوشته شده کِی باید بار شود، به‌همراه فایل‌های
مرجعی که عامل فقط اگر لازم داشت می‌خواند. هیچ‌چیزی اجرا نمی‌شود.

## نصب

```bash
npx skills@latest add OWNER/hone --skill '*'            # هر نُه اسکیل
npx skills@latest add OWNER/hone --skill debug-connectivity
```

یا پوشه را کپی کنید هر جا که عامل شما می‌خواند (`~/.claude/skills/`، `.agents/skills/`، یک فایل
پرامپت). تنها شرط این است که frontmatter دست‌نخورده بماند — همان چیزی است که بارگذاری را فعال می‌کند.

## چرا همین نُه تا

این‌ها لحظه‌هایی هستند که عاملِ بی‌دستور چیزی تولید می‌کند که *تمام‌شده به‌نظر می‌رسد*:

- **نمی‌تواند بداند** اتصال کار می‌کند، پس از یک promise برگشته، موفقیت اعلام می‌کند.
- **نمی‌تواند ببیند** ماشین را، پس فایروال را با تغییر کد «درست» می‌کند.
- **اندازه‌گیری نمی‌کند**، پس حلقهٔ اشتباه را بهینه می‌کند.
- **ریسک را حس نمی‌کند**، پس قالب‌بندی را مرور می‌کند و مایگریشن مخرب را نمی‌بیند.
- **نمی‌تواند بگوید نمی‌دانم**، پس در یادداشت انتشار ادعا می‌کند پلتفرمی تست شده است.

هر اسکیل با یک **تعریف انجام‌شدن** تمام می‌شود که شامل گفتنِ آن چیزی است که *بررسی نشده*. همان یک
جمله، کل دلیل وجود این بسته است.

## یک اسکیل این‌جا چه شکلی است

| قاعده | دلیل |
| --- | --- |
| محرک در description، با کلمات خود کاربر | عامل روی نشانه‌ها تطبیق می‌دهد («وصل نمی‌شود»)، نه روی نام ماژول |
| واقعیت قبل از رویه | ثابت‌ها، دستورها و متن خطاها جلوی بازاستنتاج غلط را می‌گیرند |
| بخش ضدالگو | فهرست میان‌برهای وسوسه‌انگیز از فهرست بهترین‌روش‌ها مفیدتر است |
| یک صفحه دستور، جزئیات در `references/` | عاملی که باید ۶۰۰ خط بخواند تا عمل کند، نمی‌خواند |
| تعریف انجام‌شدن، با موارد منفی | «بررسی نشده» نتیجهٔ معتبری است؛ سکوت نیست |
| بدون محتوای اجرایی | اسکیل متن است. هیچ‌چیز اینجا اجرا، نصب یا ارسال نمی‌شود |

بخش مکانیکی را مخزن اعمال می‌کند: `npm test` درستی frontmatter، تطابق نام با پوشه، طول توضیح، وجود
فایل‌های مرجع، ساختار سرتیترها و هم‌خوانی [`catalog.json`](catalog.json) با بسته را بررسی می‌کند.
[docs/fa/writing-a-skill.md](docs/fa/writing-a-skill.md) را ببینید.

## بررسی

```bash
npm test          # هر نُه اسکیل + همهٔ لینک‌های نسبی مستندات
npm run catalog   # بازسازی catalog.json بعد از افزودن یا تغییر نام یک اسکیل
```

هیچ مرحلهٔ بیلد و هیچ درخت وابستگی وجود ندارد: `node_modules` عمداً در این مخزن نیست.

**انتشار:** این پوشه از قبل یک مخزن گیت با تاریخچهٔ خواناست — [PUBLISH.md](PUBLISH.md) دو تصمیم قبل از
پوش را می‌گوید.
